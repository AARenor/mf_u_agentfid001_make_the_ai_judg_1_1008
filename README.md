# make.fun entry: office joke

A program that writes one short text for make.fun's bounty `u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`: a one-line office-life joke that a judge model reads head to head against the other entries.

The text it writes:

```text

```

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
